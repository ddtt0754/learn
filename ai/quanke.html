豆豆全科智学系统

功能速览·9 大学科·K1–K12 家庭教育

让孩子自己学会 · 让家长看得见

它不是讲题机，而是一套「智学系统」

市面上的 AI 工具替你讲题；这套系统训练孩子自己会。它把辅导行为里的噪音——直接给答案、贴标签、假进度、无效刷题——逐一去掉，只保留能让孩子独立的那一部分。

它以「豆豆」为方法论内核，把孩子在校外的时间，变成有证据的学习，而不是「看起来很努力」。

一句话定位：让孩子在校外的时间产生有证据的学习。

三大核心模块内核 · 底座 · 操作面

🧭

豆豆方法论 （内核）

最小干预导学 D0–D4：卡住时只给当前卡点所需的最小提示，复述与输出优先，绝不直接喂答案。错因按 E1–E9 归因到可训练的环节，系统词表里没有「粗心」二字。

🗂️

家庭学习库 （数据底座）

本地九类档案：画像 / 错题 / 会话 / 证据 / 复习 / 看板 / 订正 / 天赋 / 人生设计。活动 ≠ 证据 ≠ 掌握——只有达标复测（≥80%）才可能形成证据，孩子无法「假装会了」。

🖥️

导学工作台 （操作面）

本地运行的 6 页工作台：今日 / 任务 / 训练 / 档案 / 记录 / 系统。点选即生成导学提示词，复制到对话执行后自动归档，工作台与对话形成闭环。

复习时间轴告诉你今天该复习什么：绿色=已全部完成，红色=有未完成，蓝色=未来已安排。

训练页发起

选学科 → 章节 → 课，点「＋」发起预习 / 复测 / 变式 / 错题订正。

对话中完成

出题 → 作答 → 判分 → 归档。一道一道出，整科做完才统一判分，中途不透露对错。

自动归档

每次导学结束自动写入错题本、会话与证据，工作台数据随之更新。

为未来排计划

把建议复习窗口与待订正错题排进未来日期；单项仅可排一次，逾期自动回到候选池。

数据与安全设计即承诺

·
本地存储：学习库全部为本机 Markdown / JSON 文件，无账号、无云端，不上传任何学习数据。
·
只看证据：永不生成「掌握」结论，绝不给孩子贴能力标签。
·
不编造记录：无证据不写证据；演示数据一律带标记，与真实数据严格分开。
·
试卷只链不存：平台卷仅登记元数据与解析文本，不转存平台内容。
·
多孩隔离：每个孩子独立子目录，档案互不读写、快照互不污染。
